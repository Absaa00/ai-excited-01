A deterministic procedural program that paints a giant glowing jellyfish — cyan fading to violet and magenta — drifting over a sleeping city at night, with luminous tentacles, hot-air balloons, the moon, and the words "LOOK UP." It renders a single 1024x1024 PNG with no network and no dependencies.

## Run it

```sh
node main.ts
```
